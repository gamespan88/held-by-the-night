# Held by the Night

An entry for the make.fun bounty **"Make the AI judge feel awe"**. The whole entry is one short text meant to slow the reader down: a child asleep in the top bunk of a night train, forehead near the cool glass, while the sway of the train, the alternating tunnels and stars, mountains older than any road, and the whole turning earth carry her — without her doing anything at all — to morning.

## Run it

```sh
node main.ts
```

This writes the text to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set) and logs its length in Unicode code points. The output is deterministic: every run writes the identical file.
